# Label audit: instructions

60 of the 244 PlantSeg pairs that are near-duplicates by pHash but carry **different class** labels (32 drawn at random from Hamming 0 +
all 28 pairs with Hamming 2-4; order shuffled, Hamming not shown on the sheet). Generated by `analysis/label_audit.py` (seed 2).

**The only question: are the two images the same photograph?** Which label is correct is not asked; that would need a plant pathologist.

**Easy way:** `python3 analysis/label_audit_ui.py` → http://localhost:8791 (Y / N keys; each answer is written to `form.csv` immediately).

**By hand:** look at `sheet_1..6.png` (each row shows #nA and #nB with their masks) and fill in `form.csv` (LibreOffice, save as CSV).
**Do not open** `rater_model.csv` and `key.csv` before you have filled it in (independent second rater).

| Column | Value | Meaning |
|---|---|---|
| same_photo | Y | Same photograph: same scene, same moment; cropping, resizing, compression, and slight colour differences count as the same |
|  | N | Different photograph: a similar scene but a different shot (different angle, leaf, light, or object arrangement) |
| note | free text | A short reason if you like (e.g. "B is a crop of A") |

Agreement (Cohen's kappa) is computed afterwards. Whether the labels conflict is not decided by human judgement but derived automatically from the host species
(`analysis/host_conflict.py` → `host_classification.csv`): the same photograph cannot show two different botanical species; pairs of the same plant with different
diseases are additionally counted, without judgement.
