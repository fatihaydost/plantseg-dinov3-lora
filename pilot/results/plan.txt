plan.txt (written before the first real run, 10 Oct 2026; English translation)
Throughput (RTX 3050, bs2, 512 crop, bf16): ConvNeXt-T full 0.20 s/it; DINOv3 ViT-B frozen 0.19; LoRA 0.275; DINOv2 frozen 0.22.
N = 16000 iterations, batch 2 x accum 4 (effective 8) = 32,000 samples (~6 epochs; dataset paper 40k x 16 = 640k samples, 5%).
All runs use the same N, the same augmentation and the same lr schedule; the last iteration is evaluated.
Order: B0 s0, P1 s0, B0 s1, P1 s1, P2 s0, P2 s1, M2 s0, H2 (P2 + logit adjustment) s0, B0-long (N=32000) s0.
B0-long is not in the pre-registration; it was added before running to measure whether the short schedule favours the frozen backbone (deviations.md).
